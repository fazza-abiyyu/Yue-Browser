// DOCUMENTATION

Frequently
Asked Questions.

Does Yue Browser require Root access?

No. Yue Browser is designed to work optimally on all Android 8.0+ devices without requiring root access. All complex features like Adblock, Multi-thread Downloader, and Web Locker operate securely at the application level.

How does Web Locker work?

Web Locker blocks the access interface to specific domains you set (like facebook.com or banking sites). When you or someone else tries to open the site, the screen goes dark and requests mandatory biometric authentication (PIN, Fingerprint, or Face ID) from your device to proceed.

Is the Adblock engine updated automatically?

Yes, the main ad-blocking filter lists are updated automatically in the background to suppress the latest generation of ads. You can also use the "Picker" mode to create custom element blocking rules, which are saved permanently on your local device.

Can I disable forced Dark Mode on specific websites?

Absolutely. Our Universal Dark Mode algorithm is very smart at inverting colors without ruining images. However, if a website's layout breaks due to being forced dark, you can create an exception (whitelist) for that site via the per-site menu in the URL bar.
