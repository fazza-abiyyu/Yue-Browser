// DOCUMENTATION

Frequently
Asked Questions.

Does Yue Browser require Root access?

No. Yue Browser is designed to work optimally on all Android 8.0+ devices without requiring root access. It is built natively with Kotlin + Jetpack Compose on top of the Android System WebView engine.

What is Anti Open-in-App?

It prevents websites from automatically redirecting and hijacking your navigation to open external native apps (like YouTube, Shopee, or app stores). It ensures you stay completely in control inside the browser window.

Does media keep playing in the background?

Yes. Injected JavaScript hooks mock the navigator.mediaSession, which dynamically binds to Android's native MediaSessionManager. This allows audio and video to seamlessly continue playing even when you switch tabs, go to the home screen, or lock the device.

How does Web Locker work?

Web Locker blocks the access interface to specific domains you set (like facebook.com or banking sites). When you or someone else tries to open the site, the screen goes dark and requests mandatory biometric authentication (PIN, Fingerprint, or Face ID) from your device to proceed.

Is Yue Browser related to the Yue library in C or C++?

No. Yue Browser is an independent mobile web browser application built specifically for Android using Kotlin and Jetpack Compose. It is completely unrelated to the "Yue" C++ library (which is a library for creating native cross-platform GUI applications) or any C language modules.
